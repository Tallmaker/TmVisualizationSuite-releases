# Mode settings

The property panel shows only the settings of the selected mode. Each group of mode settings is in **Appearance**.

- **Violin settings** and **Raincloud settings**: Density detail, box plot, raw observations, and summary box.
- **Beeswarm settings** and **Dot histogram settings**: Mark size. Dot histogram also has Bin width, Fixed bin width, Fixed bin count, and Show bin counts.
- **ECDF settings**: Show markers at step vertices.

**Orientation** sets the direction of the category axis for Violin, Raincloud, Beeswarm, and Dot histogram. The value stays when you change the mode. The shared settings set text size, colors and legend, tooltip, number format, and axes and gridlines.
