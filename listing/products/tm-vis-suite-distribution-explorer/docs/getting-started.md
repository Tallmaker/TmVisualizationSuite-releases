# Set up an object

Drag **Tm Distribution Explorer** from **Custom objects** to the sheet. Add up to three dimensions and two measures in **Data**. In **Data roles**, select a mode in **Chart type**, then map one field for each role of that mode.

**Value** is the measure whose distribution the chart shows, and it is required in every mode. **Observation** is one member of the population. **Category** gives one distribution for each category value, and **Group** splits a category. **Secondary value** is a Raincloud role.

Without an Observation field, Qlik calculates one value for each Category and Group. The chart then shows the distribution of these aggregate values.
