Tm Visualization Suite: Distribution Explorer shows the whole spread of a number on one Qlik sheet object. Violins and rainclouds show the shape of each group, a beeswarm shows every single value, a dot histogram counts values in bins and a cumulative curve shows how many fall below each level.

Click a group, a bin or a point to select the values behind it, and the rest of the sheet follows. The charts read your data and never change it. Very large data sets are shown as a density, with a note on how many values are drawn.
