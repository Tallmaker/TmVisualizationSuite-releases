# Mode settings

The property panel shows only the settings of the selected mode. Each mode keeps its own settings.

- **Bullet settings**: Orientation, Better result.
- **Waterfall settings**: Compare actual with, Item values can be added, Orientation, Axis start, Better result.
- **Variance bars settings**: Compare actual with, Orientation, Show difference as, Item order, Better result.
- **Target band settings** and **Pace to target settings**: Period, Time scale. Pace to target also has Better result.

**Maximum rows** sets the most rows that the chart loads. The shared settings set text size, colors and legend, value labels, tooltip, number format, axes and gridlines, and row spacing.
