# Selection

A mark selects the dimension value behind it. Bullet, Waterfall/bridge, and Variance bars select the Item value. In Waterfall/bridge, only the bars of the items select; the total bars and the connectors do not. Target band and Pace to target select the Period value; only the Actual points select, and Plan, Target, the band, and the boundary lines do not.

Qlik owns the confirmation of a selection. Use the Qlik toolbar to confirm or cancel, or press Escape.

Press Tab to move focus into the chart, use the arrow keys, Home, or End to move between marks, and press Enter or Space to select. Page Up, Page Down, or scroll changes the visible window.
