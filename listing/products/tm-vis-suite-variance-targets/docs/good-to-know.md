# Notices and limits

A notice line states when the chart shows less than the full result. The chart prefers a reduced view with a notice to a refusal.

- Above **Maximum rows**, Item modes keep the first items and Period modes keep the latest periods. Waterfall/bridge refuses, because it needs all items.
- The chart states when it removes rows with a missing value, when a range is missing or inverted, and when periods have gaps.
- An axis that does not start at zero is marked on the total bars.

A state panel replaces the chart when the selection has no rows, a required role has no field, the data fields cannot be used together, or the item values are not confirmed as additive.
