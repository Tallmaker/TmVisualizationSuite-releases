# Set up an object

Drag **Tm Variance & Targets** from **Custom objects** to the sheet. Add the dimension and measures that the mode needs. In **Variance & Targets**, select a mode in **Chart type**, then map one field for each role.

**Item** is one category and **Period** is one date bucket. **Actual** is the observed value. **Reference** is the Plan, Prior, or Target field that **Compare actual with** selects; it is not a separate field. Map each scenario first.

Item modes need one row for each Item. Period modes need one row for each Period. Actual, Plan, Prior, Target, Lower, and Upper must describe one measure with one unit and one period basis.
