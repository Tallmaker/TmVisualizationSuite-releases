# Mode settings

The property panel shows only the settings of the selected mode. Each group of mode settings is in **Appearance**.

**Show labels** turns the node labels on or off for each mode. **Orientation** applies to Icicle and Dendrogram, and each of the two modes keeps its own value. **Label direction** applies to Icicle. Choose Vertical when a rectangle is narrow and tall. A label can end with an ellipsis when it does not fit; hover over the node to read the full label.

The shared settings set text size, colors, and tooltip. The Size values use the number format of the Size measure in Qlik.
