# Selection and navigation

The drawn nodes are the selection surface. Click a node to select it, or drag a rectangle to select all nodes in it. A node selection selects the full path of that node in Qlik: one value for each level from Level 1 down to the node. Qlik shows its selection toolbar. Confirm or cancel the selection there, or press Esc.

Double-click a node to zoom in to it. Zoom is navigation and does not change the Qlik selection. The path of the zoomed node shows above the chart. Click **Whole hierarchy** or a node name in the path to go back up.

Press Tab to move focus into the chart, use the arrow keys to move between nodes, and press Enter or Space to select.
