# Set up an object

Drag **Tm Hierarchy Explorer** from **Custom objects** to the sheet. Add one dimension for each hierarchy level, up to eight, and one measure for the size. In **Data roles**, select a mode in **Chart type**.

Map **Level 1 (root)**, then map each next level. The dropdown for a level shows after you map the level above it. **Size** is required for Sunburst, Icicle, and Circle packing. Each row of the data is one full path from Level 1 down to the deepest mapped level. Qlik adds the sizes up to the parents.

Dendrogram and Radial dendrogram show the tree structure without a Size measure.
