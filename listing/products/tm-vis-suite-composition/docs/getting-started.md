# Set up an object

Drag **Tm Composition** from **Custom objects** to the sheet. Add the dimensions and one measure. In **Composition**, select a mode in **Chart type**, then map one field for each role.

**Category** is the part of the whole. **Split** is an optional second division in 100% stacked proportion, Waffle, and Unit chart, and it is required in Marimekko / mosaic and Parallel sets. **Value** is the size of a part. Use one measure, and make all parts use one unit.

Turn on **Parts can be added** only when the Value is not negative, the Value is additive, each source row belongs to one part, and all values use one unit. No chart draws while the setting is off.
