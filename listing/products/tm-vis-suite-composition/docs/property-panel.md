# Mode settings

The property panel shows only the settings of the selected mode. Each mode with settings has its own group.

- **100% stacked proportion settings** and **Marimekko settings**: Orientation, Show Other.
- **Waffle settings** and **Unit chart settings**: Show Other, Value per unit.
- **Parallel sets** has no mode settings.

**Maximum rows** sets the most rows that the chart loads. **Item order** applies to 100% stacked proportion. The shared settings set text size, colors and legend, value labels, tooltip, number format, and axes and gridlines. Share text uses a percent pattern, not a currency pattern.
