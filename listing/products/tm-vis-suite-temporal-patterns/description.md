Tm Visualization Suite: Temporal Patterns is a Visualization family for Qlik Cloud. It answers how values change over time and which daily or seasonal pattern repeats. The family has six modes: Calendar heatmap, Ridgeline, Horizon, Cycle, Streamgraph, and Seasonal heatmap.

Every mode uses a Time field and a Value measure. Ridgeline and Streamgraph also use a Series field. Cycle and Seasonal heatmap also use a Cycle field. Qlik calculates each value before the chart draws it.

A click on a mark selects the Qlik time value, series, or cycle behind it. A notice states when a chart draws fewer periods or series than the result holds. The family reads the app data and does not change it.
