# Mode settings

The property panel shows only the settings of the selected mode. Each group is in **Appearance**.

- **Calendar heatmap settings**: Show values on days, Week starts on, Allow date selections.
- **Ridgeline settings**: Show filled areas, Show latest values, Series limit.
- **Horizon settings**: Magnitude bands, Negative direction, Show values.
- **Cycle settings**: Show period summary, Show values, Label leader lines, Period limit.
- **Streamgraph settings**: Baseline, Show layer labels, Series limit.
- **Seasonal heatmap settings**: Show values in cells, Show period summary, Period limit.

The shared settings set text size, colors and legend, tooltip, number format, and axes and gridlines. The **Axes and gridlines** settings apply to Ridgeline, Horizon, and Cycle.
