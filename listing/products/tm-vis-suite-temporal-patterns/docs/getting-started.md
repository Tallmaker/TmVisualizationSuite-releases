# Set up an object

1. Drag **Tm Temporal Patterns** from **Custom objects** to the sheet.
2. Open the property panel and add fields in **Data**.
3. In **Data roles**, select a mode in **Chart type**.
4. Map one field for each role of the mode.

Every mode uses **Time** and **Value**. Ridgeline and Streamgraph also use **Series**. Cycle and Seasonal heatmap also use **Cycle**. A field that you add in **Data** and do not map to a role has no effect on the chart.

Qlik calculates each Value before the chart draws it. Use **Styling** to set the background color of the object.
