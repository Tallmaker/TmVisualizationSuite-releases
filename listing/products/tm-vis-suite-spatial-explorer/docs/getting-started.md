# Set up an object

1. Drag **Tm Spatial Explorer** from **Custom objects** to the sheet.
2. In **Data**, add the Observation, Latitude, and Longitude dimensions and the Weight measure.
3. In **Data roles**, map one field for each role.
4. In **Appearance**, open **H3 aggregation settings** and set **H3 resolution (0 to 15)**.
5. Set **Country outline** to On or Off.

The property panel sections appear in this order: Data, Data roles, Sorting, Add-ons, Appearance, Styling, and About. A field that you add in Data and do not map to a role has no effect on the map.
