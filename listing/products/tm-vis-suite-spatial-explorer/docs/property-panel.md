# H3 aggregation settings

**H3 aggregation settings** is the first group of **Appearance**.

- **H3 resolution (0 to 15)** sets the size of the hexagon areas. The default is 7. A higher number gives smaller areas.
- **Background map URL template** adds a background map. Use a tile template with z, x, and y placeholders, or a WMS GetMap template with bbox, width, and height placeholders.
- **Background map attribution** adds the credit text under the map.

The country outline uses Natural Earth country borders at 1:50m scale. It needs no credit and makes no network request. The shared settings set text size, colors and legend, and tooltip.
