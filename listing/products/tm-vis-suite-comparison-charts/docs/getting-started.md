# Set up an object

Drag **Tm Comparison Charts** from **Custom objects** to the sheet. Add the dimensions and measures that the mode needs. In **Data roles**, select a mode in **Chart type**, then map one field for each role.

**Category** is required in every mode. **Series** groups the categories. **Stage** gives the columns of a Slopegraph or a Bump chart. **Value** is the measure to compare. Dumbbell uses **End A** and **End B**. Range plot uses **Minimum** and **Maximum**, with optional **Actual** and **Target**.

**Data detail** states how many rows the data has for each category. Use Category for Dumbbell, Cleveland dot plot, and Range plot. Use Category-stage for Slopegraph and Bump chart.
