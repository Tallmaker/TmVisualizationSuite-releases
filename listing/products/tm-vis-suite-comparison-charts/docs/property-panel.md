# Mode settings

The property panel shows only the settings of the selected mode. Each group of mode settings is in **Appearance**. Slopegraph has no mode settings.

- **Dumbbell settings**: Show connectors, Row density.
- **Cleveland dot plot settings**: Row density, Sort order, Stem to baseline.
- **Range plot settings**: Row density.
- **Bump chart settings**: Rank direction.

**Orientation** sets the direction of the category axis for Dumbbell, Cleveland dot plot, and Range plot. The shared settings set text size, colors and legend, tooltip, number format, value labels, and axes and gridlines. **Stem to baseline** draws a line from the value-axis baseline to each dot and turns the Cleveland dot plot into a lollipop.
