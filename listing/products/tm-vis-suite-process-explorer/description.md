Tm Visualization Suite: Process Explorer is a Visualization family for Qlik Cloud. It answers how cases move through events and stages. The family has seven modes: Trace, Swimlane, Event sequence, Milestone, Journey, State transition, and Funnel.

Case is the instance of the process. Event, Stage, and Occurrence name what happens. Start and End are measures that return a date or a time for each row. Weight sets the size of a transition or a stage. Qlik calculates every value before the chart draws it.

A click selects the case, the occurrence, the event, or the stage behind the mark. A notice states when the chart shows a reduced result. The family reads the app data and does not change it.
