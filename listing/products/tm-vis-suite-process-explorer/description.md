Tm Visualization Suite: Process Explorer shows how cases move through a process on one Qlik sheet object. See each order as a row of events, group the work by team in lanes, line up the steps of many cases, mark milestones, or follow the typical journey from stage to stage.

Click a case or an event to select the data behind it, and the rest of the sheet follows. The charts read your data and never change it. Large event logs show the busiest cases first, with a note on how many are shown.
