# Notices and limits

A notice line under the chart states when the chart shows less than the full result. The chart loads at most 20,000 rows.

- The Swimlane draws the latest 5,000 timed occurrences. Above that count it does not draw connectors.
- The chart states when it does not draw overlapping occurrences, or when it keeps the latest milestones, the most common paths, or the first transitions.
- Rows without a required value are not drawn.

A state panel replaces the chart when the selection has no rows, a required role has no field, or the data shape does not fit the mode. The Swimlane is a lane timeline; do not use it when you need one row for each case.
