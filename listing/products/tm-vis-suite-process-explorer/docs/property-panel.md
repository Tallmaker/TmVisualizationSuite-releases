# Mode settings

The property panel shows only the settings of the selected mode. Each group of mode settings is in **Appearance**. Funnel has no mode settings.

- **Trace settings** and **Event sequence settings**: Sort cases by.
- **Swimlane settings**: Show event text, Color by, Stage connectors.
- **Milestone settings** and **Journey settings**: Show date text.
- **State transition settings**: View, Show values on transitions, Show totals.

The shared settings set text size, colors and legend, value labels, tooltip, and number format. **Color by** sets the Swimlane bar color and legend to Stage or Event.
