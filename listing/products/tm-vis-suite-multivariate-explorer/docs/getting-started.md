# Set up an object

Drag **Tm Multivariate Explorer** from **Custom objects** to the sheet. Add one dimension for the Observation and two to twelve measures. In **Multivariate Explorer**, select a mode in **Chart type**.

Select the Observation dimension, then map **Measure 1** and **Measure 2**. The dropdown for a slot shows after you map the slot above it. The slot order sets the order of the measures in the chart.

**Maximum observations** sets the largest number of observation values that the chart loads. The default and the maximum are 20,000. A mode needs at least two mapped measures.
