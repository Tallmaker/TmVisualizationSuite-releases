# Mode settings

The property panel shows only the settings of the selected mode.

- **Labels** sets the measure labels to Full, Short, or None.
- **Show correlation coefficients in cells** applies to the Correlation matrix.
- **Highlight** fades the unselected dots or lines, and the chart still uses every observation.
- **Draw every observation** draws up to 30,000 dots or 5,000 lines. When it is off, the chart samples up to 3,000 dots or 300 lines evenly.

The shared settings set text size, colors and legend, tooltip, number format, and axes and gridlines.
