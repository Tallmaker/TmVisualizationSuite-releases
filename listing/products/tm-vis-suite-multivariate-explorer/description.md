Tm Visualization Suite: Multivariate Explorer compares many measures at once on one Qlik sheet object. A correlation matrix shows which measures move together, a scatter plot matrix draws every pair of measures against each other, and parallel coordinates follow each store across all measures as one line.

Select a year or a group in Qlik and every view follows. The charts read your data and never change it. Large data sets are shown as a sample, and a note says how many observations are drawn.
