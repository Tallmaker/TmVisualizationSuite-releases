# Mode settings

The property panel shows only the settings of the selected mode. Each group of mode settings is in **Appearance**.

- **Chord, Network, and Arc settings**: Node ordering, and Label density for Network and Arc.
- **Alluvial settings**: Stage ordering and Label density.
- **Adjacency matrix settings**: Row ordering and Column ordering.

The shared settings set colors and legend, tooltip, and text size. The Time role shows one snapshot at a time. Use the arrows above the chart to move to the previous or the next time value.
