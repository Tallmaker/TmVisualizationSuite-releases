# Selection

The drawn nodes and links are the selection surface. Click a mark to select it, or drag a rectangle to select all marks in it.

- A node selects that source or target value. A link selects the source and target pair.
- An Alluvial stage block selects that value in that stage. An Alluvial flow selects the source, target, and stage combination.
- A matrix header selects that source or target value. A matrix cell selects the source and target pair.

An empty matrix cell has no selection target. A rectangle that covers marks of different kinds does not make a selection. The Time arrows change the visible snapshot and do not make a selection. Press Tab to move focus into the chart, use the arrow keys to move between marks, and press Enter or Space to select.
