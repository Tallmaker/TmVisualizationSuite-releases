# Set up an object

Drag **Tm Relationship Explorer** from **Custom objects** to the sheet. Add up to five dimensions and one measure. In **Data roles**, select a mode in **Chart type**, then map one field for each role.

**Source** and **Target** are required in every mode. **Weight** sets the size of a relationship. **Category** colors a relationship. **Stage** is required for Alluvial. **Time** shows one snapshot at a time.

**Data detail** states what one row of the data is. Use Edge for one row per source and target pair, which is the default for Chord, Network, Arc, and Adjacency matrix. Use Edge-stage for Alluvial. **Maximum rows to request** defaults to 5,000.
