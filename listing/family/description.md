Tm Visualization Suite adds ten Visualization families to Qlik Cloud. Each family is a separate extension with its own modes and author guide.

The families answer different questions: time patterns, distributions, comparisons, relationships, hierarchies, many measures, process flows, areas on a map, plan against actual, and parts of a whole. The modes of one family share their data roles, so you can change the mode without a new data setup.

Qlik calculates every value before a chart draws it. A click selects the Qlik value behind a mark. Each family states when it draws less than the full result. Install one family, several families, or all ten.
