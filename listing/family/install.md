Install the Tm Licensing carrier extension on Qlik Cloud before you add a family.

1. In Administration, open Extensions, then Add.
2. Install the carrier zip. Keep the extension file name unchanged.
3. Install each family zip from the same Extensions page.
4. Reload the open Qlik pages.

One carrier serves every family. The families read it when a sheet opens, and the check is offline. Do not add Tm Licensing to a sheet.
